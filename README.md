# text-to-video

テキストを入力すると、指定した文字色・背景色・文字サイズ・配置で画像を作り、それを **MP4動画** として書き出すツールです。ストップウォッチ／タイマーをオプションで追加することもできます。サーバーを使わず、ブラウザだけで完結し、初回アクセス後は**オフラインでも利用可能**です。

GitHub Pages で公開して、そのままブラウザから使えます。

## デモ

`index.html` を GitHub Pages で公開すると、以下の URL でアクセスできます。

```
https://<ユーザー名>.github.io/text-to-video/
```

## 使い方

1. 入力欄に表示したい文字を入力する
2. 文字色（初期値 `#FFFFFF`）と背景色（初期値 `#000000`）をカラーピッカーまたは16進数入力で指定する
3. 文字の配置を「左揃え」「中央揃え」から選ぶ（初期値は左揃え）
4. スライダーで文字サイズを調整する（プレビューにリアルタイムで反映される）
5. 必要であれば「ストップウォッチ」または「タイマー」をオプションで有効にし、時間を分単位（小数可、例: 1.5分）で指定する
   - 有効にすると画像サイズは自動で 720×360 になり、テキストの下に時計が別行で表示される
   - 表示形式は「分:秒」（例: `3:07`）
6. プレビューで最終的な見た目を確認する
7. 「動画を生成する」ボタンを押すと動画が生成される
   - 時計オプションが「なし」の場合：これまで通り 720×240・1fps・1秒間（静止画1フレーム）の動画
   - 時計オプションが有効な場合：720×360・1fpsで、実際に時間が進む動画（長さは指定分数+1秒）。ストップウォッチは `0:00` から指定時間まで、タイマーは指定時間から `0:00` までカウントする
8. 「ダウンロード」ボタンでファイルとして保存、または「共有」ボタンで端末の共有シートから共有できる

## 機能

- 文字色・背景色をカラーピッカー／16進数コードの両方で指定可能
- 文字の配置（左揃え／中央揃え）を切り替え可能
- 文字サイズはスライダーで調整でき、プレビューに即時反映
- 長い文字列は自動で改行・縮小し、枠内に収まるように描画
- ストップウォッチ／タイマーをオプションで追加可能（分単位で指定、表示は秒付き「分:秒」）
  - 有効時は画像サイズが 720×360 になり、テキストの下に時計が表示される
  - 実際に時間が経過する動画として書き出される（長さ＝指定分数+1秒、1fps）
  - 生成中は進捗バーで状況を確認可能
- 生成される動画は `.mp4`（H.264 / Baseline profile）
- ダウンロード機能（`<a download>` によるローカル保存）
- Web Share API による共有シート表示（対応端末のみ）
- **オフライン対応**：Service Workerにより初回アクセス後はネット接続なしでもページ表示・操作・動画生成（MP4変換含む）が可能

## 技術構成

- 素のHTML / CSS / JavaScriptのみで実装（フレームワーク・ビルド不要）
- `<canvas>` にテキスト・時計を描画してプレビューを作成
- [WebCodecs API](https://developer.mozilla.org/ja/docs/Web/API/WebCodecs_API)（`VideoEncoder` / `VideoFrame`）でcanvasの各フレームを直接H.264にエンコード
- [`mp4-muxer`](https://github.com/Vanilagy/mp4-muxer)（**リポジトリに同梱・`vendor/mp4-muxer.js`**、軽量なJS製MP4マルチプレクサ）でエンコード済みのフレームをMP4コンテナに格納
  - CDNに依存せずローカルファイルとして同梱しているため、オフラインでも動画生成が可能
- 巨大なWASMエンジン（ffmpeg.wasm等）を使わないため、初回読み込み・生成ともに高速
- Service Worker（`sw.js`）がページ・スクリプト・依存ライブラリをキャッシュし、2回目以降のアクセスをオフライン対応にする
- 外部への送信は行わず、すべてブラウザ内（クライアントサイド）で完結

## オフライン対応の仕組み

- 初回アクセス時、`sw.js` が `index.html` / `vendor/mp4-muxer.js` / `manifest.webmanifest` などをキャッシュに保存します。
- 2回目以降のアクセスでは、ネット接続がなくてもキャッシュから読み込まれ、ページ表示・プレビュー編集・MP4動画生成・再生まで一通り行えます。
- ページ右上に「オフライン利用可」バッジが表示されたら、Service Workerの準備が完了した合図です。
- `sw.js` 内のキャッシュはバージョン管理されており（`CACHE_VERSION`）、ファイルを更新した場合はこの値を変更することでキャッシュが更新されます。

## 動作環境について

- 動画生成には **WebCodecs API**（`VideoEncoder` / `VideoFrame`）が必要です。2024年以降の Chrome / Edge など Chromium系ブラウザで動作します。Safari や Firefox は対応状況が限定的なため、非対応の場合はその旨を画面に表示します。
- WebCodecsに対応していない環境では動画生成ができません。その場合はChromeやEdgeなど対応ブラウザでの利用をご案内ください。
- オフライン機能には Service Worker のサポートが必要です。ほとんどのモダンブラウザで対応しています。
- 共有ボタンは `navigator.share` / `navigator.canShare` に対応した環境（主にスマートフォンのブラウザ）でのみ共有シートが表示されます。非対応環境では代わりにダウンロードをご利用ください。
- タイマー／ストップウォッチを長時間（数十分など）に指定すると、フレーム数が多くなり生成に時間がかかります。生成中は進捗バーで状況を確認できます。

## リポジトリ構成

```
text-to-video/
├── index.html              # メインページ（UI・描画・エンコード処理）
├── sw.js                   # Service Worker（オフラインキャッシュ）
├── manifest.webmanifest    # PWAマニフェスト
├── vendor/
│   └── mp4-muxer.js        # mp4-muxerライブラリ（同梱・CDN不要）
└── README.md
```

## GitHub Pages での公開手順

1. このリポジトリの `index.html` / `sw.js` / `manifest.webmanifest` / `vendor/` フォルダをリポジトリのルートに配置する（フォルダ構成を保つこと）
2. GitHub の Settings → Pages を開く
3. Source を `Deploy from a branch` にし、ブランチを `main`（または該当ブランチ）、フォルダを `/ (root)` に設定する
4. 数分待つと、公開URLが表示される
5. 一度ページを開いてService Workerの登録が完了すれば（右上に「オフライン利用可」と表示される）、以降はオフラインでも利用できる
